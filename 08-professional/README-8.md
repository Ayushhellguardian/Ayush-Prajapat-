## Escalation Email — Activity

**Scenario:** SIEM alert flagged unusual login activity on the admin portal.

---

**To:** supervisor@company.com  
**Subject:** [SECURITY ALERT] Suspected Brute Force — Admin Portal

Hi [Supervisor Name],

I am escalating a potential security incident from today's monitoring shift.

**What was detected:**
- 47 failed login attempts in 8 minutes on the admin portal
- All attempts from a single IP: `185.220.101.47`
- Target account: `admin@company.com`
- No successful logins confirmed

**Actions already taken:**
- Verified alert is not a false positive
- Documented all timestamps and event details

**Recommended next steps:**
1. Block IP `185.220.101.47` at the firewall
2. Temporarily lock the targeted admin account
3. Audit other accounts for similar activity
4. Review last 48 hours of logs for successful logins from unusual IPs

Standing by for your instructions.

Best regards,  
[Your Name] — SOC Analyst Tier 1
