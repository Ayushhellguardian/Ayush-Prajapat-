## What This Course Covers

This course introduces the cybersecurity field — its history, core concepts, and the tools and frameworks that security professionals use daily.

---

## Key Topics

### The 8 CISSP Security Domains
The Certified Information Systems Security Professional (CISSP) framework organizes cybersecurity into 8 domains:

1. **Security and Risk Management** — Policies, ethics, compliance, risk
2. **Asset Security** — Protecting physical and digital assets
3. **Security Architecture and Engineering** — Secure system and network design
4. **Communication and Network Security** — Protecting network infrastructure
5. **Identity and Access Management (IAM)** — Who gets access to what
6. **Security Assessment and Testing** — Audits, penetration testing
7. **Security Operations** — Incident response, log monitoring
8. **Software Development Security** — Secure coding practices

### Common Attack Types
- **Phishing** — Deceptive emails/messages to steal credentials
- **Malware** — Viruses, ransomware, spyware, trojans
- **Social Engineering** — Manipulating people to bypass technical controls
- **SQL Injection** — Injecting malicious database commands
- **Man-in-the-Middle (MitM)** — Intercepting communication between parties
- **Denial of Service (DoS/DDoS)** — Flooding systems to make them unavailable

### Core Security Tools
| Tool | Purpose |
|------|---------|
| SIEM (e.g. Splunk, Chronicle) | Collects and analyzes security event logs |
| Firewall | Filters network traffic based on rules |
| IDS/IPS | Detects and prevents suspicious network activity |
| Antivirus | Detects and removes malware |
| Playbooks | Step-by-step guides for incident response |
| Wireshark / tcpdump | Network traffic capture and analysis |

### Brief History of Cybersecurity
- **1988** — Morris Worm: one of the first recognized worms on the internet
- **1990s** — Rise of the commercial internet → new attack surfaces
- **2000s** — Organized cybercrime, nation-state attacks emerge
- **2010s** — Major breaches: Target, Yahoo, Equifax; ransomware spreads
- **2020s** — AI-powered attacks, supply chain attacks, zero-day exploits
